# IPv4 Price Aggregator

Полноценный Streamlit-дашборд для мониторинга актуальных цен на блоки IPv4.

## Возможности

- **Живые цены аренды** с LARUS API (обновление в реальном времени)
- **Цены покупки** по всем 5 RIR-регионам (Европа, Америка, Азия, Африка, Латинская Америка)
- **Выбор региона** и размеров блоков
- **Графики** (Plotly): сравнение тарифов, динамика во времени
- **История цен** в локальной SQLite-базе
- **Автообновление** каждые 5 минут (опционально)
- Красивые таблицы и интерактивные графики

## Установка (macOS / Linux / Windows)

```bash
# 1. Перейти в папку
cd ipv4_aggregator

# 2. Создать виртуальное окружение (рекомендуется)
python3 -m venv venv
source venv/bin/activate          # macOS / Linux
# или: venv\Scripts\activate     # Windows

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Запустить
streamlit run app.py
```

После запуска откроется браузер по адресу `http://localhost:8501`.

## Структура проекта

```
ipv4_aggregator/
├── app.py              # Основной Streamlit-дашборд
├── data_sources.py     # LARUS API + рыночные цены
├── db.py               # Работа с SQLite (история)
├── requirements.txt
├── README.md

```

## Как обновляются данные

| Источник          | Тип          | Частота          |
|-------------------|--------------|------------------|
| LARUS API         | Аренда       | Каждые 5 мин (кэш) |
| Рыночные отчёты   | Покупка      | Снимки при запуске |
| SQLite            | История      | При каждом обновлении |

## Автозапуск на macOS (launchd)

Можно создать `~/Library/LaunchAgents/com.ipv4.aggregator.plist` для фонового запуска.

## Примечания

- Цены покупки основаны на публичных рыночных данных (IPv4Center, IPv4.Global, CircleID) на сентябрь 2026.
- Для максимально точных котировок покупки рекомендуется дополнительно смотреть живые листинги на маркетплейсах.
- LARUS API — публичный endpoint для расчёта аренды.
